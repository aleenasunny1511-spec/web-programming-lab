CSS (Cascading Style Sheet)

1. Inline CSS
Inline CSS is used to apply unique styles directly to a single HTML element by utilizing the style attribute inside the HTML tag
2. Internal CSS
Internal (or embedded) CSS is defined within a < style > tag located inside the < head > section of a single HTML document. It controls the styling for that specific page.
3. External CSS
External CSS isolates styles completely into a separate file with a .css extension. This external file is linked to the HTML page using the tag inside the section
